# رحلتي للتطوير · 90 يوم

تطبيق أندرويد عربي لمتابعة العادات والمهام اليومية في القرآن والإنجليزية والمختبرات الطبية والتصميم. يعمل محلياً دون حساب أو اتصال، ويحتفظ بالبيانات على الجهاز.

## بناء التطبيق

1. ثبّت Android Studio مع Android SDK Platform 35 وJDK 17.
2. افتح المشروع في Android Studio وانتظر مزامنة Gradle، أو على Windows شغّل `build-apk.bat`.
3. ينتج ملف التثبيت في `app/build/outputs/apk/debug/app-debug.apk` ونسخة باسم `rahla90.apk` في جذر المشروع.

## الميزات

- خطة مرنة من 90 يوماً، ومهام دورية بحسب المسار.
- تسجيل الإنجاز، متابعة التقدم والسلسلة، سجل الأيام، ومراجعة أسبوعية.
- إضافة مهام شخصية وتغيير بداية الخطة.
- تصدير واستيراد نسخة احتياطية JSON عبر منتقي ملفات أندرويد.
- أيقونة تطبيق مستوحاة من الصورة المرفقة، وواجهة عربية RTL.

كل البيانات تبقى على الهاتف؛ احفظ نسخة احتياطية قبل تغيير الجهاز أو حذف التطبيق.
